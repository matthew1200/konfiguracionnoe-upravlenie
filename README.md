# Вариант 20 — эмулятор UNIX-оболочки

Практические работы по конфигурационному управлению, РТУ МИРЭА, ИКБО-16-25.

Этап 1: графическое окно Tkinter, приглашение к вводу, парсер с поддержкой
`$HOME` и `${VAR}`, заглушки `ls` и `cd`, команда `exit`, сообщения об ошибках.

Запуск из корня проекта:

```bash
python -m src.main
python -m unittest discover -s tests -v
```

Этап 2: параметры запуска `--vfs` и `--script`, отладочное отображение
параметров в GUI, стартовые сценарии с комментариями `#` и выводом ошибок.
Вызовы тестовых сценариев из Windows: `scripts\\run_config.bat` и
`scripts\\run_script_only.bat`.
