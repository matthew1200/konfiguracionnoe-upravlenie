ВАРИАНТ 20 — КОНФИГУРАЦИОННОЕ УПРАВЛЕНИЕ
=====================================

КРАТКО: ЧТО НУЖНО ПОКАЗАТЬ ПРЕПОДАВАТЕЛЮ

1. Откройте PowerShell в папке проекта variant20_shell.
2. Запустите:
   py -3 -m unittest discover -s tests -v
   Это запускает все автоматические проверки.
3. Запустите:
   py -3 -m src.main --vfs data/nested.json --script scripts/startup_full.txt
   Это открывает GUI и выполняет полный демонстрационный сценарий.
4. Покажите заголовок окна вида «Эмулятор - [имя@компьютер]».
5. Покажите автоматический вывод команд, комментарии (# пропускаются),
   отладочные параметры и сообщения об ошибках в сценарии.
6. Введите вручную (последовательно):
   ls
   cd docs
   ls
   cd notes
   tac lines.txt
   cd ../..
   date
   date +%Y-%m-%d
   echo "$HOME"
   cp hello.txt file-copy.txt
   ls
   cp -r docs copied-docs
   ls copied-docs/notes/archive
   ls no-such-path
   cp docs without-r
   exit
7. Объясните: файлы загружаются из JSON в оперативную память; cp меняет
   только этот объект, реальный JSON-файл на диске не меняется.
8. Покажите остальные типы VFS через scripts/run_minimal.bat,
   scripts/run_simple.bat и scripts/run_nested.bat.
9. Покажите историю этапов:
   git log --oneline --reverse

КОМАНДЫ ОС И ЧТО ОНИ ЗНАЧАТ

py -3 -m src.main                  запустить GUI с VFS по умолчанию
py -3 -m src.main --vfs ...        выбрать другой JSON-файл
py -3 -m src.main --script ...     исполнить стартовый сценарий
py -3 -m unittest discover -s tests -v
                                    проверить работу тестами
git status                          посмотреть состояние репозитория
git log --oneline --reverse         увидеть пять этапов разработки
git remote -v                       посмотреть адрес привязки к GitHub

КОМАНДЫ ЭМУЛЯТОРА

ls [путь]             вывести имена файлов и папок
cd [путь]             сменить текущую папку
cd ..                 подняться на папку выше
tac file.txt          вывести строки файла в обратном порядке
date                  показать локальные дату и время
date +%Y-%m-%d        показать дату по заданному формату
clear                 очистить содержимое терминала
cp a.txt b.txt        создать копию файла
cp a.txt docs/        скопировать файл в папку
cp -r docs docs-copy  рекурсивно скопировать каталог
echo "$HOME"          показать реальный домашний каталог ОС
exit                  закрыть приложение

ВАЖНО:
- Встроенный терминал — не настоящий Windows PowerShell/Linux Bash.
- JSON физически не модифицируется; cp влияет только на текущий сеанс.
- При перезапуске программы изменения из предыдущего сеанса исчезают.
- Для Windows используйте команды py -3; для Linux обычно python3.
- Результат загрузки в GitHub надо выполнить самостоятельно из своего
  аккаунта: проект сейчас содержит только локальную историю Git.
